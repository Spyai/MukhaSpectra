# MukhaSpectra

Point-of-care oral cancer **screening and triage** aid by SparkyAI Private Limited.

> **Research prototype — not for clinical use.** MukhaSpectra flags suspicious findings and assigns
> a risk level. It is a screening aid, not a diagnosis: final diagnosis requires a clinician and
> histopathology.

See [`docs/architecture.md`](docs/architecture.md) for the plan.
